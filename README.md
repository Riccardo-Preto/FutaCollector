# FutaCollector

Android app for browsing and searching **One Piece Trading Card Game** cards.

⚠️ Work in progress project built for learning Android development with Kotlin and Jetpack Compose.

---

## 📱 Features (Current)

- View list of card sets
- Search cards by name
- Fetch card data from external API
- Simple and clean UI using Jetpack Compose

---

## 🚧 Planned Features

- Show card images
- Add Starter Deck and Promo filtering
- Save favourite cards
- Improve search speed and filters
- Offline caching
- Collection tracker

---

## 🛠 Tech Stack

- Kotlin
- Jetpack Compose
- Retrofit
- Coroutines
- Android Studio

---
